Example

A permanent MarkerSeek demonstration using the bundled Salvia plastome dataset.

Demo dataset

The demo job uses the annotated Salvia plastomes distributed in test_data/, with Salvia_chinensis.gb as the coordinate and annotation reference.

true

Expected runtime

On a small server, the analysis usually completes in a few minutes. Primer design adds extra MAFFT and in-silico PCR work after the candidate markers are selected.

What you will see in the results page

The results page shows Pi and similarity previews, downloadable TSV and figure files, and a Candidate markers table. Each row links to a hotspot detail page and reports the label, plastome region, feature length, Pi, alignment reliability, MarkerSeek score, and primer availability.

What you will see in a detail page

Detail pages combine feature metadata, a local Pi curve, an alignment viewer, haplotype network, species PCA, primer ranking table, and FASTA/CSV downloads for the selected candidate marker.

How to interpret the MarkerSeek score

Higher scores indicate candidates with stronger polymorphism, cleaner alignment, useful conserved flanks, stronger species-level evidence, and more suitable amplicon length. Scores are comparative within a run rather than absolute biological guarantees.
