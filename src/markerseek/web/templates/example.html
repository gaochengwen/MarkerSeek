Demo dataset and analysis design

The demonstration compares annotated plastomes from 18 Salvia samples. The reference file defines coordinates, feature names, and plastome regions; all candidate labels and detail pages are projected onto that reference coordinate system.

Input set

The demo uses GenBank files from test_data/. The selected coordinate reference is Salvia_chinensis.gb.

Output scope

MarkerSeek writes sliding-window Pi results, candidate-marker features, haplotypes, summary figures, primer outputs, and interactive feature payloads for the selected candidates.
