Help

MarkerSeek identifies plastid genome candidate markers from annotated GenBank files.

Overview Inputs Parameters Output Files Score Interpretation Primer Design Detail Page Walkthrough Citation FAQ

Overview

MarkerSeek aligns plastomes with MAFFT, estimates nucleotide diversity, detects high-Pi hotspot regions, scores candidate markers, and writes downloadable tables and figures. A permanent worked example is available on the Example page.

Inputs

  • Upload between 2 and {{ max_files }} GenBank files with .gb, .gbk, or .genbank extensions.
  • Total upload size is limited to {{ max_upload_mb }} MB.
  • The selected reference defines coordinates, annotations, region labels, and candidate-marker names.
  • If no reference is selected, MarkerSeek uses the first sorted input file.

Score Interpretation

The MarkerSeek score is a 0-100 normalized weighted sum. It rewards Pi, variable-site density, informative indels, conserved flanks, alignment reliability, species resolution, barcoding gap, nearest-neighbor discrimination, and suitable marker length. Missing within-species diagnostics contribute no positive score and are shown as insufficient replicates when the dataset lacks at least two samples per species.

Primer Design

Primer design scans conserved flanks around candidate markers, calls primer3, then tests each pair against every sample by in-silico PCR. The 3-prime anchor must match exactly, while the remaining primer body can tolerate the configured mismatch count. Primer scores combine primer3 penalty, cross-sample amplification success, and amplicon information content.

Detail Page Walkthrough

Use the Candidate markers table's View details button to inspect a hotspot. The detail page shows metadata, a Pi curve with SNP and indel positions, an alignment viewer, haplotype network, species PCA, primer ranking, and feature-level FASTA/CSV downloads.

Citation

Please cite MarkerSeek and the underlying methods and software: Hebert et al. 2003, Meyer and Paulay 2005, Untergasser et al. 2012, Katoh and Standley 2013, and Nei and Li 1979.

FAQ

Why do some diagnostics say "Insufficient replicates"?

Those diagnostics require at least two samples from the same species. Single-sample species can support interspecific comparisons but cannot estimate within-species behavior.

Why are only some rows clickable?

The Candidate markers table contains hotspot candidates with detail payloads, so every displayed row is clickable. The downloadable feature table contains the broader feature inventory.

How long are web jobs retained?

Ordinary jobs are retained for {{ retention_days }} days. The bundled example job is permanent.
