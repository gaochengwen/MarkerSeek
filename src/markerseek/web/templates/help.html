Help

MarkerSeek computes nucleotide diversity across annotated chloroplast GenBank files.

Input requirements

  • Upload {{ max_files }} or fewer GenBank files with .gb, .gbk, or .genbank extensions.
  • At least two files are required for nucleotide diversity analysis.
  • Total upload size is limited to {{ max_upload_mb }} MB.

Results

  • Each submission returns a job ID for status checks and downloads.
  • Successful jobs include Pi tables, feature tables, PDF figures, PNG previews, and a ZIP archive.
  • Files are retained for {{ retention_days }} days.
